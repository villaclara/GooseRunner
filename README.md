Developed in [Unity](https://unity.com/) with C#, this mobile game features a code with object-oriented patterns and object pooling for optimized performance on mobile hardware. 
The project integrates Unity Ads for monetization, but ads are disabled in the WebGL build and the APK release on Itch.io. 
All visuals were hand-drawn, giving the game a unique and polished design.

## Where to play
- Android build (.apk) available to download on itch.io
- WebGl version to play in any browser - https://villaclara.github.io/gooserunner-webgl.
